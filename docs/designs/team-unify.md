# 팀으로 통합 — 그룹 개념 없애기 + 팀을 목록 칸에서 관리 (2026-10-13 사장님)

## 요청
> 팀으로 그룹을 통합하는 게 맞다. 그룹을 임시로 만들어 쓰는 일은 많지 않다. 팀에 두 기능을 통합하고,
> 팀 기능을 팝업이 아니라 화면 왼쪽 영역에서 편리하게 보고 관리하게.

## 지금(0.21.2)
| | 🎬 그룹(목록 보기) | 👥 팀·경력(설정 → 고급 → 팝업) |
|---|---|---|
| 저장 | `monitor_groups.json`(mongroups) | `team.db`(team·teamlog) |
| 기능 | 관제 화면·호출선·폰 알림(4종) | 구성원(에이전트·세션 교체 이력)·일감 승인/반려·경력·토큰·규칙 위반·사람 입력 기록·보존본 |
| 원격(폰) | 됨(`/api/owner/monitor/groups`) | **안 됨**(`/api/v1/team` 로컬 전용, E-2) |
| 관계 | 팀 → 그룹 한 방향 자동 맞추기(구성원·라벨) | |

실데이터: 그룹 6 = 팀 연결 3(KP·NKLAW·NKLAWSVC) + 보관 팀의 남은 그룹 1(P2P Test) + 그룹만 2(개발관리에이전트 = KP 부분집합, 워커 스킬 테스트).

## 결정
| # | 결정 | 이유 |
|---|---|---|
| U1 | **화면·말에서 「그룹」을 없앤다. 팀 = 세션 묶음(관제·알림) + 일 장부.** `mongroups` 는 팀의 관제·알림 엔진으로 **내부에만** 남는다(팀당 1개, 사용자 화면 노출 없음) | 알림 훅(monwatch)·관제 WS·알림 클릭 `#monitor=<gid>` 를 그대로 재사용 — 검증된 경로를 다시 짜지 않는다 |
| U2 | **팀 없는 그룹은 Host 기동 때 한 번 팀으로 옮긴다**(이름·구성원·라벨·알림 설정 유지, 그룹 id 그대로 팀에 연결). 보관된 팀에 남은 그룹은 지운다 | 사장님 데이터 무손실. 옮긴 팀은 필요 없으면 한 번에 보관 |
| U3 | **팀 보관 = 관제 그룹 삭제(알림 멈춤)**, 보관 풀기 = 다시 만듦 | 지금은 보관해도 알림이 남고, 그룹만 지우면 감시가 다시 만든다 |
| U4 | **사장님 팀 API(`/api/owner/teams…`)를 새로 연다** — 읽기 전부 + 사장님 직접 동작(구성원 추가·빼기, 알림 설정, 이름 바꾸기). 폰(릴레이)에서도 된다. 에이전트용 `/api/v1/team` 은 로컬 전용 그대로 | 그룹이 폰에서 되던 것을 잃지 않는다. 폰은 이미 모든 세션 대화를 보는 사장님 기기 — 팀 장부가 더 민감하지 않다. E-2(에이전트 경로) 는 유지 |
| U5 | 팀 만들기·보관·보존본 지우기·일감 승인/반려는 **지금처럼 승인 요청**(사람 증명). 화면에서 만든 요청은 `/api/owner/approvals`(생성·실행)로 — 폰에서도 | A-3 유지. 지금 화면의 승인 요청은 로컬 전용 경로라 폰에서 안 됐다 |
| U6 | 구성원 추가·빼기·알림·이름은 **승인 없이 바로**(지금 그룹 편집과 같은 무게) | 사장님이 화면에서 한 동작 = 사람. 팀 생성만 무겁게 |
| U7 | 관제 화면의 💾 저장/갱신 버튼을 없앤다. 관제 중 ＋ 세션 추가는 **이번 관전에만**(저장 안 함) | 구성원의 정본은 팀. 💾 로 그룹을 바꾸면 팀 맞추기가 되돌린다 |
| U8 | 설정 → 고급의 「👥 팀·경력」 팝업을 없애고 「👥 팀 보기로」 이동 버튼만 둔다. 「사장님 프로필」은 팀 보기의 🧑‍💼 개인비서 칸으로 | 입구 하나(ux-reorg 원칙 4) |

## 화면 — 목록 칸의 「👥 팀」 보기
보기 전환 `세션 | 👥 팀 | 📁 파일` (내부 키는 `groups` 그대로 — 기기에 기억된 값 호환).

```
┌ 목록 칸 ─────────────────────────────┐   ┌ 상세 칸(PC) ─────────┐
│ 🧑‍💼 개인비서        ● 실행 중   ▸     │   │  선택한 팀의 관제    │
│ ─────────────────────────────────── │   │  (지금 그룹 관제 그대로)│
│ 👥 KoreaPedia  KP          🎬  ▾    │   │                      │
│   구성원 8 · 🟢 3 · 진행 2 · 제출 1⚠  │   └──────────────────────┘
│  [구성원][일감 3][기록][⚙]           │
│   🟢 개발관리 (관리) · 관리   생성 중 │ ← 누르면 세션 열기
│   ⚪ 로동신문 · 로동신문 서비스  경력›│ ← 경력은 그 줄 아래 펼침
│   ＋ 구성원 추가                      │
│ 👥 북한법 박사논문 NKLAW    🎬  ▸    │
│ ＋ 새 팀                              │
│ 🗄 보관된 팀 2  ▸                     │
└─────────────────────────────────────┘
```
- **팀 칸 머리**: 이름·코드, 요약 줄(구성원 수·실행 중 수·진행/제출/막힘 일감, 제출된 일감이 있으면 ⚠ 강조). 머리를 누르면 펼침/접힘 + PC 는 오른쪽에 관제. 🎬 = 관제 열기(폰은 전체 화면).
- **펼친 칸 탭**(기기에 기억): 
  - **구성원**: 상태 점·별칭·관리 표시·역할·지금 상태 → 누르면 그 세션. `경력›` = 그 줄 아래에 토큰·메시지·제출/승인/반려·세션 이력·맡은 일감. 편집 모드에서 `빼기`. `＋ 구성원 추가` = 세션 고르기·별칭·역할 칸이 그 자리에 펼쳐짐.
  - **일감**: 진행 중 / 제출됨 / 전체. 줄을 누르면 그 아래 타임라인. 제출된 일감은 `✔ 승인 · ✖ 반려`(승인 요청 → 같은 자리 승인 시트).
  - **기록**: 토큰 합·구성원별, 규칙 위반, 사람 입력 검색(검색칸 + 결과 그 자리).
  - **⚙**: 알림 4종 토글, 이름 바꾸기, 🗄 보관(승인), 🧽 보존본 지우기(승인).
- **🧑‍💼 개인비서 칸**(포트폴리오 팀): 비서 세션 열기 · 사장님 프로필(확정/거절은 승인 요청).
- **＋ 새 팀**: 그 자리에 이름·관리 세션·구성원(세션별 별칭) 칸 → 승인 요청.
- **보관된 팀**: 접힌 묶음, 펼치면 읽기 전용 칸 + `보관 풀기`(승인).
- 승인 시트·확인처럼 **사람 증명이 필요한 순간만** 기존 시트를 쓴다(팝업 금지는 '보고 관리하는 화면'에 대한 것).

## 서버
- `team.adopt_groups()` (U2) — 기동 1회 + 감시 주기마다(멱등): 팀이 가리키지 않는 그룹 → 팀(관리 = manager 세션, 별칭 = 라벨 앞부분 또는 '관리'), `monitor_group_id` 연결. 보관된 팀이 가리키는 그룹은 삭제.
- `team.archive(on)` → 그룹 삭제 + `monitor_group_id=NULL`(U3). 풀면 `sync_group` 이 새로 만든다.
- `team.rename(team_id, name)` → 팀 이름 + 그룹 이름.
- `team.owner_view(ref)` → 한 번에: 팀(구성원 + 세션 상태) · 일감 · 토큰 · 위반 · 알림 설정.
- 라우트(U4·U5): `GET /api/owner/teams[?archived=1]`, `GET /api/owner/teams/{t}`, `…/tasks/{id}/timeline`, `…/members/{a}/history`, `…/inputs`, `GET /api/owner/team-agents/{id}`, `POST …/members`, `…/members/{a}/leave`, `…/notify`, `…/rename`, `POST /api/owner/approvals`(생성, requested_by=`owner`), `POST /api/owner/approvals/{id}/execute`.

## 테스트
- 서버: adopt_groups(무손실·멱등·보관 팀 그룹 삭제), archive ↔ 그룹, owner 라우트(릴레이 경유 허용 · `/api/v1/team` 는 여전히 403), owner 승인 생성·실행.
- PWA: 팀 칸 렌더(요약·펼침·탭 기억), 구성원 → 세션 열기, 경력 펼침, 일감 승인 버튼 → 승인 요청, 새 팀 폼 → team_create 인자, 설정의 팀 팝업 제거.

## 남기는 것
- 에이전트(clewpath-workers 스킬)는 지금처럼 `/api/v1/team` 으로 팀을 다룬다 — 스킬 변경 없음.
- `/api/owner/monitor/groups` 라우트는 옛 앱 호환으로 남기되 화면은 쓰지 않는다.
