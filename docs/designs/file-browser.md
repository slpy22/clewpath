# 기획: 세션 파일 브라우저 (📁 파일 보기, VS Code 사용감)

- 상태: **기획(검토 대기)** — 2026-10-12 사장님 요청
  - "세션, 그룹 보기 외에 선택된 세션의 폴더와 그 안의 파일들을 볼 수 있는 브라우저"
  - 추가: "**VS Code 와 유사한 사용감**이 되게"
  - 구현 전 결정 사항(§10)부터 확정
- 관련: 목록 보기 전환(Host 0.16.4, `LIST_VIEW`), 릴레이 제네릭 API 프록시(connector `_handle_api`), exporter.py(작업 폴더 포함 내보내기), CLAUDE.md 불가침 원칙

## 1. 왜 필요한가

폰·원격에서 claude 에게 일을 시키면 **결과물이 파일로** 남는다(보고서 md, 코드, 이미지, 추출 데이터). 지금은 그걸 보려면:
- 터미널에서 claude 에게 "파일 내용 보여줘" 라고 시키거나(토큰·컨텍스트 소모, 대화가 오염됨)
- PC 앞에 가야 한다.

목표 사용 장면
- S1 워커가 "산출물: `docs/report.md`" 라고 답했다 → 폰에서 바로 열어 읽는다(Ctrl+P 로 이름 쳐서 열기).
- S2 "방금 claude 가 뭘 바꿨지?" → 탐색기에서 **M/U 색 표시**(git) 와 최근 변경 순으로 보고 연다.
- S3 claude 가 지금 고치고 있는 파일을 열어 두면 **바뀔 때마다 자동 갱신**된다.
- S4 생성된 이미지·PDF·CSV 를 확인하거나 내려받는다.
- S5 (Phase 2) 바뀐 내용을 **diff** 로 본다 / 폰 사진·파일을 세션 폴더에 올려 claude 에게 넘긴다.

## 2. "VS Code 와 비슷한 사용감" 의 정의

| VS Code 요소 | 이 기능에서 | Phase |
|---|---|---|
| 탐색기(Explorer) 트리 — 폴더를 **그 자리에서 펼치기/접기**(화면 이동 없음) | 왼쪽 트리, 펼친 상태 기억 | 1 |
| 편집기 탭 — **한 번 클릭 = 미리보기 탭**(기울임, 다음 클릭에 교체), 두 번 클릭/스크롤 = 고정 | 같은 규칙 | 1 |
| 편집기 화면 — 문법 색, 줄 번호, 접기, 미니맵, Ctrl+F 찾기 | **Monaco 편집기**(VS Code 의 바로 그 편집기)를 읽기 전용으로 | 1 |
| 편집기 위 이동 경로(breadcrumbs) | 파일 경로 표시, 누르면 탐색기에서 그 폴더 | 1 |
| Markdown 미리보기 | md 는 미리보기/원문 전환 | 1 |
| 이미지 미리보기 | 이미지 탭 | 1 |
| Ctrl+P 빠른 열기(파일 이름 퍼지 검색) | 상단 검색 칸 + 단축키 | 1 |
| git 표시 — 수정(M, 주황)/새 파일(U, 초록)/삭제, 폴더에도 점 | `git status` 기반 장식 | 1 |
| 바깥에서 파일이 바뀌면 열린 탭이 자동 갱신 | 열린 탭 수정 시각 확인(몇 초 간격) | 1 |
| 다크 테마·아이콘 | 기존 앱 다크 + 파일 종류 아이콘(최소 세트) | 1 |
| 소스 제어 diff 보기 | Monaco diff 편집기(작업본 vs HEAD) | 2 |
| 전체 검색(Ctrl+Shift+F, 내용 검색) | 서버 측 검색(ripgrep 류, 상한) | 2 |
| 편집·저장 | **보류** — claude 와 동시 수정 충돌 | Deferred |

모바일은 VS Code 를 그대로 옮길 수 없으므로: 탐색기는 **왼쪽 서랍**(☰ 로 열고 닫음), 편집기가 전체 화면, 탭은 위에 가로 스크롤.

## 3. 범위 — Phase 구분

**Phase 1-a (탐색 + 보기의 뼈대)**
- 탐색기 트리(지연 로딩, 펼친 상태 기억), 무거운 폴더(`.git`, `node_modules`, `.venv`, `__pycache__`, `dist`) 흐리게 + 항목 수 안 셈
- 편집기 탭(미리보기 탭 규칙), breadcrumbs
- Monaco 읽기 전용(문법 색·찾기·접기·미니맵), Markdown 미리보기, 이미지 미리보기, 그 외는 정보 + 내려받기
- 정렬: 이름(폴더 먼저, VS Code 기본) / 최근 변경
- 민감 파일 차단(§6), 크기 상한

**Phase 1-b (VS Code 다움 완성)**
- Ctrl+P 빠른 열기(서버가 파일 목록 색인, 제외 폴더·상한 적용, 캐시)
- git 장식(M/U/D, 폴더 전파) — `git status --porcelain` 1회/새로고침
- 열린 탭 자동 갱신(외부 변경 감지), 탐색기 새로고침 버튼

**Phase 2 (고도화)**
- diff 보기(작업본 vs HEAD, Monaco diff), 전체 내용 검색
- 대화 → 파일 연결: 뷰어·관제의 도구 이벤트(Write/Edit 경로)를 누르면 그 파일·diff 를 연다
- 업로드(지정 하위 폴더 `_uploads/`, 덮어쓰기 금지, 2FA)
- PDF 미리보기, 큰 파일 구간 읽기

**Deferred (수요 확인 후)**
- 편집·저장·삭제·이름 바꾸기(claude 동시 수정 충돌, 되돌리기 책임). 필요하면 "claude 에게 시키기"(터미널에 지시 문구 넣기)로 대체
- 세션 cwd 밖 임의 경로 탐색

## 4. 화면

목록 상단 전환에 세 번째 칸: **「세션 | 🎬 그룹 | 📁 파일」**. 세션 상세에도 **📁 파일** 바로가기.

- 📁 파일은 **선택된 세션**(마지막으로 연 세션)의 cwd 를 연다. 머리에 세션 이름 + 바꾸기. 없으면 "세션을 먼저 고르세요" + 최근 세션 바로가기.
- 같은 폴더를 쓰는 세션이 여럿이면(예: `E:\019_KoreaPedia` 12개) 어느 세션으로 열어도 같은 탐색기.

데스크톱(2단 그대로 활용)
```
┌ 목록 칸 ─────────────────┐┌ 상세 칸 ──────────────────────────────────────┐
```

## 5. 서버 API (Host)

| 동사·경로 | 용도 |
|---|---|
| `GET /api/sessions/{id}/files?path=<상대>&sort=name\|mtime` | 폴더 한 단계 목록. `{root, path, entries:[{name,type,size,mtime,blocked,heavy}], truncated}` |
| `GET /api/sessions/{id}/file?path=<상대>&mode=text\|raw` | 파일 내용. text = UTF-8(실패 시 cp949) 문자열 + 언어 힌트, raw = base64. 상한 초과 `413` |
| `GET /api/sessions/{id}/file/stat?paths=a,b,…` | 열린 탭 자동 갱신용 수정 시각 묶음 조회(1-b) |
| `GET /api/sessions/{id}/files/index` | Ctrl+P 용 파일 경로 목록(제외 폴더, 상한 20,000, 30초 캐시)(1-b) |
| `GET /api/sessions/{id}/git/status` | git 장식(저장소 아니면 빈 값)(1-b) |

- 경로는 **세션 cwd 기준 상대 경로만**. 서버가 `resolve()` 후 뿌리 안인지 검사(`..`, 절대 경로, 심볼릭 링크·정션 탈출 거부).
- 한 폴더 항목 상한 1,000개(넘으면 `truncated`).
- 릴레이는 지금의 제네릭 `/api/*` 프록시를 그대로 탄다(JSON 응답). 바이너리는 base64.
- 크기 상한(초안): 텍스트 2MB(Monaco 는 큰 파일도 버티지만 릴레이 전송 고려), 이미지·내려받기 10MB(릴레이) / 20MB(로컬).
- 읽기만 하므로 claude 파일 불가침 원칙(1)에는 닿지 않는다. `~/.claude` 는 §6 에서 아예 차단.
- git 은 `git status --porcelain=v1 -z` 를 **읽기 전용**으로만 실행(타임아웃 5초). 인덱스 잠금을 잡지 않도록 `GIT_OPTIONAL_LOCKS=0`.

## 6. 보안 — 이 기능의 핵심 위험

원격(폰·릴레이)에서 **PC 파일 내용을 읽는 길**이 새로 생긴다. 지금도 터미널로 claude 에게 시키면 읽을 수 있어 권한이 새로 생기는 건
아니지만, 클릭 몇 번으로 빠르게 대량으로 볼 수 있게 되므로 다음을 지킨다.

1. **뿌리 고정**: 세션 cwd 밖은 못 본다. cwd 가 드라이브 맨 위(`C:\`, `E:\`)면 거부.
2. **홈 폴더 세션 주의**: 실제로 cwd 가 `C:\Users\slpy2` 인 세션이 있다(2026-10-12 확인). 홈을 뿌리로 열면 아래 차단 목록이 모두 걸린다.
3. **항상 차단(로컬·원격 모두, 목록에도 안 보임)**: `~/.claude/`, `.ssh/`, `AppData/`, ClewPath 데이터 폴더, 브라우저 프로필.
4. **민감 파일 — 이름은 보이되 내용은 막음(🔒)**: `.env*`, `*.pem`, `*.key`, `*.pfx`, `id_rsa*`, `*credentials*`, `*secret*`, `*.kdbx`,
   `cp_credentials.json`, `devices.json`, `ptyd.key`, `release-keys/` 아래 전부(이 프로젝트의 `ops/release-keys/private.pem` 이 그 예).
   Ctrl+P 색인·내용 검색에서도 제외.
5. **원격 권한(결정 §10-2)**: 기본안 = 페어링된 기기면 탐색·보기 허용, **내려받기는 2FA**.
6. **감사 기록**: 원격 열람·내려받기는 `api_audit.jsonl` 에 남긴다(기기·파일·크기).
7. Monaco·Markdown 렌더는 파일 내용을 **코드로 실행하지 않는다**: Markdown 은 sanitize(DOMPurify), SVG 는 `<img>` 로만(스크립트 무력화).
8. 쓰기 계열(Phase 2 업로드)은 특권 경로(`_PRIV_API_SUFFIXES`)로 2FA.

## 7. 프런트 구성

- **Monaco**: `vendor/monaco/` 에 고정 버전 동봉(min 기준 수 MB). **📁 파일을 처음 열 때만** 지연 로드 → 평소 앱 로딩 무영향.
  릴레이 모드에서도 vendor 는 CP 정적 경로(E2EE 터널 아님)로 받는다. 모바일 Safari 에서 읽기 전용 표시·스크롤·찾기 동작은 1-a 첫 작업으로 스파이크 확인.
- Monaco 모델은 탭마다 1개, 탭 닫으면 dispose(메모리).
- 테마: VS Code Dark+ 계열(기존 앱 다크 색과 맞춤). 아이콘은 최소 세트(폴더·코드·문서·이미지·데이터·잠금).
- 상태 기억(기기별): 세션별 펼친 폴더, 열린 탭, 정렬.

## 8. 성능

- 탐색기는 폴더 단위 지연 로딩(`os.scandir` 1회).
- Ctrl+P 색인은 제외 폴더를 건너뛰는 걷기 + 상한 + 30초 캐시. 큰 저장소(수만 파일)는 상한에서 끊고 "일부만" 표시.
- 자동 갱신은 **보이는 탭만**, 5초 간격 stat 묶음 1회. 화면이 숨으면 멈춤.

## 9. 테스트 계획

- 서버: 경로 탈출(`..`, 절대 경로, 정션·심볼릭 링크), 드라이브 루트 거부, 차단 폴더·민감 파일(목록·내용·색인·검색 모두), 항목·크기 상한,
  인코딩(UTF-8/cp949/바이너리 판별), git 상태 파싱(저장소 아님·타임아웃), 릴레이 2FA 게이트, 감사 기록.
- PWA(node:test 하네스): 세 번째 보기 전환, 선택 세션 없음 안내, 트리 펼침 기억, 미리보기 탭 교체 규칙, Ctrl+P 퍼지 매칭,
  보호 파일 표시, 413 안내, Markdown sanitize, 자동 갱신(숨으면 멈춤). Monaco 는 하네스에서 스텁.
- 가드 테스트: 차단 목록이 빠지면 실패(`~/.claude`, `*.pem`, `release-keys`).

## 10. 결정이 필요한 것

1. **편집기 엔진**: (a) Monaco(VS Code 그 자체, 수 MB, 처음 열 때만 로드) / (b) CodeMirror 6 + 문법 색(가벼움, VS Code 와 생김새 조금 다름). → 기본안 (a).
2. **원격 권한**: (a) 페어링 기기면 보기·내려받기 모두 / (b) 보기는 허용, 내려받기는 2FA / (c) 원격은 전부 2FA. → 기본안 (b).
3. **보호 파일**: 이름만 보이고 내용 차단(🔒) vs 목록에서도 숨김. → 기본안: 이름만 보이고 차단.
4. **진행 단위**: 1-a·1-b 를 릴리스 2번으로 나눔 vs 한 번에. → 기본안: 나눔(1-a 를 먼저 써 보고 1-b 조정).

## 11. 작업량 추정

- 1-a: 서버 API·경로 검사·차단 목록 + Monaco 동봉·지연 로드 + 탐색기·탭·미리보기 + 테스트 → 큰 편(Phase 1 의 대부분)
- 1-b: 색인·Ctrl+P, git 장식, 자동 갱신 → 중
- Phase 2 는 항목별로 따로
