# 기획: 화면 재배치 — 안전성 · 사용 편의 (2026-10-12 사장님 요청)

- 상태: **1단계 구현(Host 0.18.0)** — 결정: 폰 아래 탭 막대 / 상세는 주 동작 위·위험 구역 분리 / 두 번에 나눠 배포. 2단계 구현(Host 0.19.0: 아래 탭 막대·🔔 할 일 + 목록 ⋯ 메뉴·실행 중 바로 터미널·자동 실행 기록 접기)

> "현재 필요한 기능은 초보적으로 다 들어왔다. 모든 기능·메뉴·항목의 배치를 쓰기 편하게 재배치. 가장 중요한 건 제품의 안전성과 사용자 편리성."

## 2. 문제(실화면으로 확인)

안전
- S1 세션 상세에서 **🗑 삭제·⛔ 강제 종료·↩ 되돌리기가 ✎ 이름·💬 뷰어와 같은 격자**에 섞여 있다. 손가락이 미끄러지면 위험 동작 확인창이 뜬다(확인창은 있으나 1차 방어가 배치).
- S2 위험 동작이 어떤 것인지(되돌릴 수 있나, 2차 인증이 필요한가) 버튼만 봐선 모른다.
- S3 승인 대기(사람 승인이 필요한 일)가 **설정 깊숙이** 있다 — 제때 못 보면 일이 멈춘다.

편의
- U1 **폰 머리줄이 넘친다** — PC 선택 칸 + 아이콘 4개라 ⚙ 설정이 화면 밖으로 밀려 안 보인다(iPhone 폭 390 실측, 가로 스크롤 생김).
- U2 세션 상세의 **주 동작(재개)이 맨 아래**. 폰에서는 긴 ⚙ 설명 카드를 지나 두 화면 넘게 내려야 버튼이 나온다.
- U3 상세 정보가 쓸모없는 값을 크게 보여 준다: '폴더'는 `F--fb-e2e` 같은 저장 폴더 인코딩, ID 는 8자만(복사 불가).
- U4 ⚙ "claude 재개 목록에 없는 세션" 설명이 매번 펼쳐져 화면 절반을 차지한다.
- U5 머리줄에 기능 진입(🧑‍💼 비서·🎬 관제)과 도구(⟳)가 섞여 있다. 관제는 이제 목록의 「그룹」 보기와 같은 일.
- U6 설정 한 목록에 **매일 쓰는 것(알림·승인)과 한 번 쓰는 것(스킬 설치·진단)** 이 섞여 있다.
- U7 목록 줄의 ✎(이름)는 자주 안 쓰는데 ▶ 옆 큰 자리를 차지한다(오터치로 이름 바꾸기 창).
- U8 기기 등록 안내 배너가 등록 전까지 목록 맨 위 큰 자리를 차지(나중에를 눌러도 다음에 다시).

## 3. 원칙

1. **위험한 것은 떨어뜨리고 표시한다** — 위험 동작은 맨 아래 「위험 구역」에만, 빨간 테두리, 각 버튼에 결과·2차 인증 여부 한 줄. 확인창은 그대로 유지.
2. **자주 쓰는 것은 엄지 가까이·위로** — 세션의 주 동작은 상세 맨 위. 폰은 아래 탭 막대.
3. **해야 할 일은 알림처럼** — 승인 대기는 머리줄 🔔 배지로 항상 보이게.
4. **한 곳에 한 가지** — 같은 기능의 입구는 하나(관제 = 그룹 보기).
5. 기능 삭제 없음 — 자리만 옮긴다. 원격 2FA·확인창·감사 등 안전 장치는 하나도 빼지 않는다.

## 4. 새 배치

### 4-1. 머리줄 (PC·폰 공통)
`● PC이름 ▾` · 화면 제목 · (빈칸) · **🔔 승인·알림(배지)** · **⚙**
- PC 선택은 좁은 칩(폭 제한, 넘치면 말줄임) — 폰에서 넘치지 않음.
- 🧑‍💼 비서 → 보기 전환으로(아래), 🎬 관제 → 「그룹」 보기로 합침, ⟳ → 목록은 20초 자동 갱신 + 목록 위 당겨서/버튼 새로고침, 설정 안 「새로고침」.

### 4-2. 보기 전환
- **PC**: 목록 칸 위 분할 버튼 `세션 | 그룹 | 파일 | 비서`.
- **폰**: 화면 **아래 탭 막대**(엄지 자리) `💬 세션 · 🎬 그룹 · 📁 파일 · 🧑‍💼 비서`. 터미널·편집기 전체 화면일 때는 숨김.

### 4-3. 세션 상세 (위→아래)
1. **머리**: 이름(누르면 이름 바꾸기 ✎) · 상태 배지(작업 중/대기/실행 중) · 경로 한 줄
2. **주 동작 줄**: `▶ 재개`(또는 `🖥 터미널로 돌아가기`) 크게 + `💬 대화 보기` `📂 파일` 
3. **요약**: 마지막 활동 · 메시지 수 · 모델 · 환산 비용(통계 카드 접어서 한 줄 요약, 누르면 펼침)
4. 알림 띠(있을 때만, 한 줄 + 자세히): ⚙ claude 재개 목록에 없음 / ⏩ 이어받음
5. **더 보기**(접힘): 🔱 포크로 재개 · 🛡 API 정책 · 📤 내보내기 · 📁 폴더 변경 · 세션 ID 전체(복사)
6. **위험 구역**(맨 아래, 빨간 테두리, 버튼마다 설명 한 줄):
   - ↩ 이어하기 되돌리기 — "사본을 휴지통으로, 원래 세션 유지 · 원격 2차 인증"
   - ⛔ 세션 강제 종료 — "실행 중인 claude 를 끝냄, 기록은 남음 · 원격 2차 인증"
   - 🗑 삭제 — "휴지통으로(30일 복구 가능)"

### 4-4. 목록 줄
`상태 점 · 이름 · 칩 · 시각` + 오른쪽 **▶ 하나**(승인 필요면 ✋). ✎ 이름은 상세 머리로 이동.
기기 등록 안내는 한 줄 띠(「폰 연결하기 ›」, ✕ 로 영구 숨김 → 설정에서 다시).

### 4-5. 🔔 할 일 (머리줄)
승인 대기 목록 + 권한 대기 · 입력 대기 세션 + 최근 완료(참고, 배지 제외). 관제 알림 이력은 서버 기록이 없어 보류. 배지 = 승인 대기 수. 기존 설정의 「승인 대기」는 여기로.

### 4-6. 설정 (자주 → 가끔 → 고급)
1. **연결**: 이 PC/릴레이 상태 · 내 PC(전환·추가) · 폰 연결하기(기기 추가 QR)
2. **알림**: 알림 설정
3. **보안**: 2차 인증 · 외부 접속 기기 · 이 기기 초기화
4. **데이터**: 세션 가져오기 · 휴지통
5. **업데이트**: 새 버전(있으면 맨 위로 강조)
6. **고급**(접힘): 워커 스킬 설치 · 비서 스킬 설치 · 팀·경력 · 터미널 관리 프로세스 · API 사용량 · 진단 · 새로고침

### 4-6b. 설정 재기획 (2026-10-15 사장님: "배치 순서와 항목 선택 시 화면 이행이 상당히 불편", 0.22.5)
불편했던 점 → 바꾼 것
- 항목을 누르면 설정이 닫히고 별도 창이 떠서 돌아갈 길이 없었다 → **설정 창 안에서 넘어가고 머리 왼쪽 ‹ 로 돌아온다.**
  모달 시스템에 `SETNAV` 겹 쌓기: 설정이 열려 있는 동안 openModal = 한 겹 쌓기, closeModal = 한 겹 걷기(Esc 도), ✕·바깥 = 전부 닫기.
  하위 화면 코드는 그대로 두고(끝나면 closeModal → 설정으로), 같은 제목 화면을 다시 열면 그 겹을 갈아 끼운다. 첫 화면으로 오면 상태를 다시 읽는다.
- 상태를 보려면 하나씩 눌러 봐야 했다 → **첫 화면 줄마다 지금 상태**(알림 켜짐·받는 기기 수 / 2FA 켜짐·꺼짐 / 활성 기기 수 /
  정기 작업 기준 시간 / 휴지통 개수 / 스킬 최신·새 내용 있음 / 터미널 관리 프로세스 터미널 수). 손볼 것은 주황 점·주황 글씨.
- 자주 보는 스킬 갱신이 「고급」 접기 안에 묻혀 있었다 → 접기를 없애고 쓰임새별 섹션:
  이 PC 카드 → (새 버전) → 알림·보안 → 세션(정기 작업·휴지통·가져오기·사용량) → 스킬 → 시스템(업데이트·터미널 관리·진단) → 이 기기(폰, 빨강).
- 「팀」 줄은 탭 막대 👥 와 중복이라 뺐다.

## 5. 진행
- 1단계(이번): 4-1 머리줄 · 4-3 세션 상세 · 4-4 목록 줄 · 4-6 설정 — 안전·편의 효과가 가장 큰 것
- 2단계: 4-2 폰 아래 탭 막대 · 4-5 🔔 할 일 모음
- 각 단계 테스트(PWA 하네스 + 데스크톱·iPhone 실화면) 후 릴리스
- (0.22.6, 같은 날 사장님 "GPT·Claude 처럼 좌우로") 넓은 화면(≥880px)의 설정은 **좌우 분할**: 왼쪽 = 첫 화면(메뉴, 고른 줄 강조·상태 표시 그대로),
  오른쪽 = 고른 하위 화면(처음엔 「왼쪽에서 항목을 고르세요」). 다른 메뉴를 고르면 오른쪽 겹을 걷고 새로 연다. 오른쪽 안 확인창 등은 오른쪽 머리 ‹.
  첫 항목 자동 열기는 하지 않는다 — 🔔 알림은 누르면 권한 요청이 바로 뜨기 때문. 폰은 지금처럼 한 화면씩 + ‹.
