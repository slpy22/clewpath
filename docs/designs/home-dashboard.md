# 🏠 홈 화면 개편 — "지금 무엇을 봐야 하나" (기획, 2026-10-28)

> 상태: **1차(A·B·C·D) 0.33.5 출시, 2차(E·F) 0.33.6 출시. 3차(2026-10-29) A·B·C → 열린 터미널 네 칸(§3-0) 구현.** git 미커밋. 사장님 요청(2026-10-28): "홈화면에 좀 더 의미 있는 정보들 표시하도록 기획 변경".
> 선행: quick-switch.md §3-6(빈 상세 칸 '최근 화면'), 0.32.8 🏠 홈(Alt+0).

## 1. 지금 모습과 문제

| | 지금 홈 | 문제 |
|---|---|---|
| PC | 오른쪽 칸에 "왼쪽에서 세션을 선택하세요" 한 줄 + '최근 화면' 단추 최대 4개 | 화면 대부분이 비어 있다. 무엇이 나를 기다리는지는 왼쪽 목록을 훑어야 안다 |
| 폰 | 세션 목록 칸 그대로(빈 안내는 숨김) | 목록이 길면 권한·입력 대기 세션이 아래에 묻힌다 |

홈은 **"지금 내가 손대야 할 것 → 돌고 있는 것 → 놓치면 안 되는 것"** 을 한눈에 보여 주는 자리가 되어야 한다.

## 2. 원칙

1. **새 요청을 늘리지 않는다.** 20초마다 받는 세션 목록(`/api/sessions`)에 이미 있는 값(runtime·bg·live_terminal·peer·cleanup_at·screen)으로 그린다. 예외는 §3-F 한 곳(이미 있는 API, 홈을 열 때 1번).
2. **누르면 바로 간다.** 모든 줄은 그 세션의 터미널·뷰어·상세로 한 번에 간다(기존 quickGo/openTerminal 재사용).
3. **비어 있는 칸은 숨긴다.** "볼 일 0건" 같은 빈 상자를 늘어놓지 않는다. 전부 비면 한 줄: "기다리는 일 없음 · 돌고 있는 세션 없음".
4. **읽기 전용.** 홈에서 승인·종료 같은 동작은 하지 않는다(위험 동작은 지금처럼 상세 칸 위험 구역·탭 × 에서만).

## 3. 보여 줄 것 (위에서 아래 순서)

### 0. 3차 개편(2026-10-29 사장님) — 열린 터미널 네 칸
사장님 요청: "홈 화면에서 현재 열려져 있는 터미널, 작업중, 백그라운드, 완료, 대기 상태의 터미널들을 보여 주면 좋겠어."
결정: **A·B·C 세 칸을 아래 네 칸으로 바꾼다**(같은 세션이 두 번 나오지 않게), 범위는 **실행 중인 claude 전부**
(클루패스 터미널 + 밖에서 띄운 claude + 백그라운드 에이전트 = `sessionIsLive`, 이 PC 줄의 '실행 중인 세션' 수와 같은 기준).

| 칸 | 대상 | 한 줄 | 누르면 |
|---|---|---|---|
| 🔔 대기 | 권한 대기·입력 대기(배지와 같은 30분 신선도) | ✋/💬 · 무엇을 기다리는지 · "4분째" | 터미널 |
| ⚙ 작업 중 | thinking | ⚙(조종 중이면 🛰) · "12분째" | 터미널 |
| 🐚 백그라운드 | background(턴은 끝났고 쉘·모니터·서브에이전트 남음) | 🐚 · "🐚 쉘 2" | 터미널 |
| ✅ 완료 | 위 셋이 아닌 실행 중 세션 전부(끝난 지 오래된 것 포함) | ✅ "완료"(+ 이 기기에서 끝난 뒤 안 봤으면 "· 새로") · "30분 전" / 아직 묻지 않은 것은 🖥 "열려 있음" | 터미널 |

- '방금 끝남'의 6시간·안 본 것 거르기는 없앴다. 대신 '새로' 표시로 남긴다(본 시각은 그대로 sm_seen_<PC>).
- 꺼진 세션(ready 인데 실행 중 아님)·claude -p 기록·이어진 옛 줄은 빠진다. 넷 다 비면 "열린 터미널 없음 · 기다리는 일 없음".
- 완료와 대기의 차이(사장님 질문): 완료 = Stop 훅(턴 끝, 남은 작업 없음). 대기 = Notification 훅 — 권한 대기(턴 도중 허락 기다림)
  또는 입력 대기(claude 가 보내는 "Claude is waiting for your input", 끝난 뒤 한동안 입력이 없을 때 claude 가 스스로 판단해 보낸다).
- 아래 A·B·C 는 1차 기록으로 남긴다.

### A. 🔔 지금 볼 일 — 권한·입력 대기 (가장 위, 주황)
- 대상: `runtime.phase` 가 `permission`·`waiting` 이고 신선한 것(30분 안, 🖥 볼 일 점과 같은 기준).
- 한 줄: 세션 이름 · 무엇을 기다리는지(`runtime.note` 앞 60자, 예 "Bash 실행 권한") · 기다린 시간("4분째") · [터미널로].
- 다른 기기가 보고 있으면 👀 표시(누르면 기존 인계 확인창).

### B. ⚙ 작업 중
- 대상: `thinking`(턴 진행 중) · `background`(쉘·모니터 남음).
- 한 줄: 이름 · "12분째 작업" 또는 "백그라운드 쉘 2" · 폴더 끝 이름.
- 다른 세션이 조종 중(`agent`·`peer` busy)이면 🛰.

### C. ✅ 방금 끝남 — 아직 안 본 완료
- 대상: `ready` 가 된 지 6시간 안이고, **이 기기에서 그 뒤에 그 세션을 열어 보지 않은 것**(기기별 '본 시각'을 localStorage 에 — 목록 줄의 완료 배지와 같은 근거로 맞춘다).
