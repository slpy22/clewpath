# 상세 칸 화면 바로가기 — 기획안

- 날짜 2026-10-20 · 대상 ClewPath 화면(PWA 한 파일 `pwa/index.html`) · 기획 때 버전 0.27.3(줄 번호 기준), 지금 0.28.1
- 바탕은 **C안(머리 줄 바로가기 + 화면별 '마지막 상태' 기억 — 최소 변경·폰 우선)**이고, A안(작업 표시줄)·B안(통합 탭 줄)의 좋은 점을 접붙였습니다.
- 표기: **[확인됨]** 코드를 직접 읽었거나 하네스·스크래치 프로브로 재현한 지금 동작(프로브는 2026-10-20 다시 돌려 같은 결과 확인) · **[확인 필요]** 추정이라 실기·실측이 필요한 것
- 기획 문서입니다. 제품 파일은 고치지 않았습니다.

---

## 1. 목표 (사장님 말 그대로)

> "오른쪽 영역에 자주 쓰는 화면이 터미널과 파일열람, 상세보기(뷰어) 들인데.. 이 화면들로 바로 이행 할 수 있으면 좋겠어. 그래가지고 과거에 열어 두었던 내용으로 왼쪽에서 세션이나 파일 선택 안 하고도 바로 이행 할 수 있도록. 혹시 팀 모니터링도 그렇게 바로 이행할수 있어도 좋겠고. 이거 기획부터 좀 해 봐야 할 것 같기도 해."

풀어 쓰면 이렇습니다.
- 상세 칸에서 자주 쓰는 네 화면 — 🖥 터미널 · 📄 파일 열람 · 💬 상세보기(뷰어) · 🎬 팀 관제 — 사이를
- 목록 칸에서 세션·파일·팀을 다시 고르지 않고
- 마지막에 열어 두었던 내용 그대로 오갑니다.
- PC 는 한 번 누르기(또는 단축키), 폰은 두 번 누르기.

## 2. 지금 — 현황과 왜 안 되나

### 2-1. 상세 칸의 짜임 [확인됨]
- 상세 칸에는 한 번에 화면 하나만 뜹니다. 화면을 열 때마다 칸을 통째로 비우고 새로 그립니다. 칸을 비우는 코드가 8곳에 복사돼 있고, 곳마다 정리하는 범위가 다릅니다.
- 상세 칸 화면은 8가지입니다: 세션 상세 · 대화 보기(머리 줄 제목 '뷰어') · 웹 재개 · 터미널 · 파일 편집기 · 팀 관제(PC 만. 폰은 화면 전체 덮개) · 작업 장부 · 빈 안내.
- 들어가는 길은 거의 모두 '목록 칸에서 고르기'입니다: 목록 줄 · ⋯ 메뉴 · 세션 상세의 단추 · 🔔 할 일 · 알림 · 팀 구성원 줄 · 팀 ⋯ 메뉴. 예외는 🧑‍💼 비서와, 터미널 안의 📖 이력 · ⏹ 종료 · 탭 닫기뿐입니다.
- 탭 막대는 목록 칸 보기만 바꾸고 상세 칸은 그대로 둡니다(0.22.3). PC 에서 같은 보기를 다시 누르면 아무 일도 없고, 폰 아래 탭 막대는 맨 위로 스크롤만 합니다.

### 2-2. 화면별로 기억하는 것과 돌아가는 길

| 화면 | 지금 기억하는 것 [확인됨] | 고르지 않고 돌아가는 길 [확인됨] |
|---|---|---|
| 🖥 터미널 | 열린 탭 목록과 마지막 탭(sm_tabs). 새로고침 뒤엔 탭 목록만 되살리고 '터미널을 열면 탭 스트립에 보입니다' 토스트. 화면은 열지 않음 | 없음. 탭 줄은 터미널 화면 안에서만 보임 |
| 📄 파일 | 열린 파일 탭 · 마지막 파일 · 펼친 폴더(sm_fb_state2, 복원 최대 20개) | 없음. 📁 탭은 탐색기만 보여 줌. 편집기는 파일을 누르거나 세션의 📂 로만 열리고, 📂 도 PC 이면서 터미널 화면이 아닐 때만 편집기까지 감 |
| 💬 뷰어 · ℹ 상세 | 없음. 마지막으로 본 세션을 어디에도 적지 않음 | 없음 |
| 🎬 팀 관제 | sm_mon_last(관제 id) — PC 에서 열 때만 쓰고 읽는 코드가 없음 | 👥 팀 → 팀 ⋯ → 🎬 관제 열기(4단계), 또는 관제 알림 |

입구만 없고 데이터는 대부분 있다는 것도 확인했습니다.
- 터미널: 다른 화면으로 나간 뒤에도, 새로고침 뒤에도 지난 탭 하나로 다시 열립니다 [확인됨: 하네스 P3·P5].
- 파일: 세션·파일을 고르지 않고 지난 파일 탭 줄이 돌아오고, 다시 받는 것은 마지막 파일 하나뿐입니다 [확인됨: 스크래치].
- 팀 관제: 관제 id 하나로 어디서든 여는 함수가 이미 있습니다(알림이 쓰는 길) [확인됨: 코드].

### 2-3. 왜 불편한가
- ◧ 로 목록 칸을 접으면 고를 곳이 아예 없고, 빈 칸 안내는 그때도 '왼쪽에서 세션을 선택하세요'입니다 [확인됨].
- 뷰어 막대에는 세션 이름도, 다른 화면으로 가는 단추도 없습니다(PC 에서는 '‹ 목록'도 숨김) [확인됨].
- 폰에서 '‹ 목록'은 상세 칸을 숨기기만 해서 터미널·편집기·뷰어가 살아 있는데, 다시 보여 줄 단추가 없습니다. 같은 세션 줄이나 같은 세션 알림을 눌러도 반응이 없습니다 [확인됨: 하네스 P1].
- 앱 아래 바의 '터미널' 단추는 숨은 터미널을 보여 주게 짜여 있지만, 터미널 화면이 남아 있으면 그 바를 통째로 숨기는 규칙이 있어 실제로는 누를 수 없습니다 [코드 확인됨, 실기 확인 필요].

### 2-4. 바로가기가 곧바로 밟게 될 기존 결함
바로가기가 생기면 화면을 오가는 횟수가 늘어 아래 결함이 자주 드러납니다. 그래서 먼저 고칩니다.

| 결함 | 근거 |
|---|---|
| 터미널에서 목록 줄·⋯ 로 상세·뷰어·재개·장부로 가면 터미널 화면이 정리되지 않고 연결이 열린 채 남는다. 그 뒤 릴레이 재연결·폰 화면 복귀·PC 재기동 때 보던 화면이 터미널로 바뀐다 | [확인됨: 하네스 P2·P2c·P4] |
| 뷰어·재개로 가도 '지금 터미널로 보는 세션' 표시가 남아, 그 세션 알림을 눌러도 무시된다 | [확인됨: 프로브 P2, 코드] |
| 정리된 터미널로 20초 안에 돌아오면 '다른 기기에서 보는 중' 가짜 확인창이 뜬다. 릴레이만 해당(로컬은 이 확인을 하지 않음) | [확인됨: probe3, 코드] |
| 뷰어 응답을 기다리는 사이 다른 화면으로 가면, 늦게 온 응답이 실시간 연결을 열어 둔 채 남긴다 | [확인됨: 프로브 P1] |
| 웹 재개 화면을 떠나도 재개 연결을 닫지 않는다(PC 에서는 닫는 단추가 숨어 있음). 뷰어에서 재개로 가면 뷰어 실시간 연결도 남는다 | [확인됨: 프로브 P5]. claude -p 가 페이지를 닫을 때까지 사는지는 [확인 필요] |
| 목록을 받기 전에 파일 편집기를 열면 '세션을 찾지 못했습니다'가 그 탭에 굳는다 | [확인됨: 스크래치] |
| 다른 화면에 갔다가 파일로 돌아오면 스크롤 위치를 잃는다 | [확인됨: 스크래치] |
| 같은 팀 관제가 끊긴 채 떠 있으면 '관제 열기'가 무반응. 관제가 하나라도 떠 있으면 관제 알림을 무시 | [확인됨: 코드] |
| 릴레이에서 관제·웹 재개 연결을 닫을 때 앱 쪽 처리만 지우고 PC 에 닫기 신호를 보내지 않는다(터미널만 보냄) | 앱 쪽 [확인됨: 코드, 테스트가 이 동작을 고정]. PC 쪽 파이프가 계속 도는지 [확인 필요] |
| 로컬에서 알림으로 A 를 열며 시작했는데 저장된 마지막 탭이 B 면, 화면은 A·기억은 B 로 어긋난다 | [확인됨: probe4] |
| 2차 인증 창을 취소해도 보던 뷰어의 실시간 연결은 이미 닫혀 있다(터미널 열기가 인증보다 먼저 정리) | [확인됨: 코드] |
| 기억 키에 PC 구분이 없다. 릴레이로 PC 를 바꿔 쓰면 다른 PC 의 탭 기억이 섞이거나 지워질 수 있다 | 키 구조 [확인됨], 실제로 섞이는지 [확인 필요] |

## 3. 제안

### 3-1. 왜 이 안인가 (심사 결과)

| 안 | 목표 | 단순함 | 폰 | 기존과 어울림 | 위험 낮음 | 합계(25) |
|---|---|---|---|---|---|---|
| **C 머리 줄 바로가기** | 4.5 | 4 | 4 | 4 | 4 | **20.5** |
| A 작업 표시줄(세로 막대) | 5 | 3.5 | 3.5 | 3.5 | 3 | 18.5 |
| B 통합 탭 줄 | 4 | 2 | 3 | 2 | 1.5 | 12.5 |

- C 는 칸 배치·탭 막대·탭 줄을 그대로 두고 머리 줄과 기억만 더해 가장 덜 위험하고, 화면이 덜 복잡해집니다.
- A 는 목표에는 가장 잘 맞지만 칸 배치(격자)에 칸을 하나 더해, 오늘 나온 ◧ 와 '칸 사라짐' 사고 구역을 다시 건드립니다. A 의 좋은 규칙들은 이 안에 옮겨 왔습니다.
- B 는 강력하지만 새 개념(미리보기 탭·고정·최근 닫은 탭)이 많고 고칠 곳이 가장 많습니다.

### 3-2. 한 줄로
머리 줄에 **화면 바로가기**를 둡니다(PC 는 단추 4개, 폰은 제목 ▾). 화면마다 마지막 상태를 기억해 두었다가, 누르면 그 상태로 갑니다.

### 3-3. 원칙
1. **거울 원칙** — 탭 막대는 목록 칸(왼쪽)만, 화면 바로가기는 상세 칸(오른쪽)만 바꿉니다. 0.22.3 원칙의 짝입니다.
2. **돌아가기 전용** — 새로 고르는 곳은 지금처럼 목록 칸 하나입니다(화면 재배치 원칙 4 '같은 기능의 입구는 하나').
3. **저절로 열지 않기** — 누를 때만 갑니다(다른 기기 화면을 빼앗지 않는 설계 §9).
4. **안전 장치 그대로** — 원격 2차 인증, 화면 인계 확인창, 꺼진 세션 다시 띄우지 않기(0.22.4).
5. **틀은 손대지 않기** — 칸 배치(목록 칸 | 구분선 | 상세 칸), 상세 칸 모드 CSS, 터미널 격자는 그대로 둡니다. 0.22.13·0.27.2 '칸 사라짐' 사고가 난 구역입니다.

### 3-5. 단추 상태

| 모양 | 뜻 |
|---|---|
| 파랑 | 지금 상세 칸에 떠 있는 화면. 세션 상세가 떠 있으면 💬 칸이 'ℹ 상세'로 바뀌어 파랑 |
| 보통 | 기억이 있음 — 누르면 그 상태로 |
| 흐림 | 기억이 없음 — 누르면 안내(4장) |
| 준비 중(흐림) | 새로고침 직후 첫 목록을 받기 전. 누르면 '목록을 받는 중입니다' |

- 웹 재개 · 작업 장부 · 빈 안내일 때는 파란 단추가 없습니다.
- 마우스를 올리면 무엇이 열릴지 보입니다. 예: '터미널 — 개인비서 · 입력 대기 (탭 3개) · Alt+1', '파일 — report.md 외 2 · Alt+2', '뷰어 — ClewPath 개발 · 3분 전 · Alt+3', '팀 관제 — 006 개발팀 · Alt+4'. 다른 기기가 그 터미널을 보는 중이면 '👀 다른 기기에서 보는 중 — 누르면 가져오기 확인'.

### 3-6. 빈 상세 칸 — 최근 화면 (PC)
새로고침 직후나 관제 ✕ 뒤처럼 상세 칸이 비었을 때, 안내 아래에 '최근 화면' 단추를 둡니다. 기억이 있는 것만, 마지막 화면이 맨 앞입니다.

```
┌ 상세 칸 ──────────────────────────────────────────┐
│              왼쪽에서 세션을 선택하세요              │
│              ── 최근 화면 ──                        │
│    [🖥 개인비서 외 2]        [📄 report.md 외 2]     │
│    [💬 ClewPath 개발]        [🎬 006 개발팀]         │
└───────────────────────────────────────────────────┘
```

- 목록 칸이 접혀 있으면 첫 줄을 '◧ 로 목록 칸을 펼치거나 최근 화면으로 가세요'로 바꿉니다(지금 문구는 접힘 상태에서 틀린 말).
- 폰은 빈 안내 자체가 숨겨져 있어(지금 동작) 해당이 없습니다.

### 3-7. 단축키 (PC)
- Alt+1 터미널 · Alt+2 파일 · Alt+3 뷰어(마지막이 상세였으면 상세) · Alt+4 팀 관제 (결정 8).
- 받지 않는 경우: 검색칸 · 이름 입력 · 한글 입력창 같은 진짜 입력칸에 커서가 있을 때, 설정 창 · 확인창 · ⋯ 팝이 열려 있을 때, Ctrl·Shift 가 함께 눌렸을 때.
- 터미널·파일 편집기 안에서는 받습니다(가장 필요한 곳). 릴레이 터미널은 이 조합을 claude 로 보내지 않습니다.
- 로컬 화면(127.0.0.1:5100)의 터미널은 화면 속 별도 문서(iframe)라, 그 안에 커서가 있으면 키가 바깥으로 오지 않습니다. 같은 출처라서 터미널 창이 열릴 때 같은 키 감시를 붙이는 방법을 씁니다 [확인 필요: 실기]. 안 되면 terminal.html 이 이 조합만 바깥으로 넘겨줍니다.

## 4. 화면별 동작

**공통 규칙**
- 이미 그 화면이 떠 있으면 다시 짓지 않고 커서만 옮깁니다.
- 2차 인증이나 화면 인계 확인을 취소하면 지금 화면 그대로입니다. 칸은 그 관문을 통과한 뒤에만 정리합니다.
- 연달아 누르면 마지막 누름만 화면을 바꿉니다.
- 기억은 누를 때 지금 목록·팀 목록으로 확인하고, 없어졌으면 그 기억만 지우고 알립니다.
- 바로가기는 새 터미널 탭이나 새 claude 를 만들지 않습니다.

### 4-1. 🖥 터미널
- **지난 상태**: 마지막으로 보던 터미널 탭. 탭 줄의 나머지 탭과 탭별 '권한확인' 설정도 그대로입니다. 그 탭이 없으면 가장 최근에 본 탭.
- **누르면**: 목록에서 그 세션 줄을 누른 것과 같은 길로 엽니다.
  - 릴레이(폰 등): 2차 인증 유예를 확인합니다. 유예가 끝났으면 6자리 코드를 묻고, 취소하면 그대로입니다.
  - 다른 기기가 보고 있으면 지금의 인계 확인창이 뜹니다.
  - 돌아오는 비용은 지금 탭 칩을 누를 때와 같습니다. 로컬은 터미널 창을 다시 읽고, 릴레이는 화면 내용을 한 번 다시 받습니다(설계 문서 기준 약 60KB). 스크롤은 맨 아래에서 시작합니다.
- **이미 떠 있으면**: 그대로. 폰에서 '‹ 목록'으로 숨겨 둔 것이면 다시 보여 주기만 합니다(재접속 없음). 연결이 끊겨 있으면 같은 탭에 다시 붙습니다.
- **지난 상태 없음**(탭 0개): 흐린 단추. 누르면 '열어 둔 터미널이 없습니다 — 세션 줄의 🖥/▶ 로 여세요'. 목록 칸이 접혀 있으면 펼치고 세션 보기로(결정 5).
- **세션이 꺼짐**(쉬는 세션 4시간 정리·⏹ 종료 등): 판정 전에 목록을 한 번 새로 받습니다. 목록은 20초마다 오므로 방금 띄운 터미널을 꺼진 것으로 잘못 볼 수 있기 때문입니다. 그래도 꺼져 있으면 목록 줄과 같은 규칙으로, 그 탭을 닫고 그 세션 상세(▶ 재개)를 엽니다. 새 claude 는 띄우지 않고 '꺼진 터미널이라 상세로 열었습니다 — ▶ 재개로 다시 띄울 수 있어요'를 띄웁니다(결정 4).
- **지워짐·이사**(목록에 없음): 그 탭을 조용히 내리고 다음 최근 탭으로. 없으면 '지난 상태 없음'과 같습니다.
- **다른 기기가 가져감**: 툴팁·시트에 👀 를 미리 보이고, 누르면 지금의 확인창을 거칩니다. 자동으로 되찾지 않습니다.

### 4-2. 📄 파일
- **지난 상태**: 열어 둔 파일 탭들과 마지막 파일(최대 20개). 같은 창 안이면 내용과 스크롤 위치까지.
- **누르면**: 편집기가 그 모습으로 뜹니다. 내용이 메모리에 있으면 네트워크를 쓰지 않습니다. 새로고침 뒤에는 마지막 파일 하나만 다시 받습니다(릴레이는 PC 감사 기록 'file_view' 한 줄). 목록 칸 보기는 바꾸지 않습니다(거울 원칙).
- **이미 떠 있으면**: 그대로(폰에서 숨겨 둔 것이면 다시 보여 주기만).
- **지난 상태 없음**: 목록 칸을 📁 탐색기로 바꾸고(접혀 있으면 펼침) '파일을 고르세요'. 고를 곳이 왼쪽뿐이라 이 경우만 왼쪽을 바꿉니다.
- **세션이 꺼짐**: 영향 없습니다. 서버는 꺼진 세션으로도 그 폴더를 찾습니다 [코드 판독].
- **지워짐**: 그 폴더를 쓰는 세션이 목록에 하나도 없으면 그 탭에만 '세션을 찾지 못했습니다'(목록을 새로 받은 뒤 한 번 다시 시도해, 지금처럼 영구 오류로 굳지 않게). 파일 자체가 지워졌으면 지금 문구 '파일이 없습니다'. 🔒 보호 파일은 지금처럼 내용을 열지 않습니다.
- **낡은 내용**: 같은 창에서 오래전에 받은 내용은 그대로 보입니다. 다듬기 단계에서 ⟳ 다시 읽기를 둡니다.

### 4-3. 💬 뷰어 · ℹ 상세 (한 칸)
- **지난 상태**: 마지막으로 본 대화 보기 또는 세션 상세의 세션. 어느 길로 열었든(목록 줄 · ⋯ · 🔔 · 알림 · 팀 구성원 · 📖 이력) 기록합니다. 단추 이름이 마지막 종류를 따라 💬 뷰어 / ℹ 상세로 바뀝니다(결정 1). 웹 재개를 보다 떠났으면 그 세션의 대화 보기로 기억합니다(재개는 새 claude 를 띄우고 원격은 2차 인증이 필요해 바로가기 대상이 아님).
- **누르면**: 목록의 최신 세션 정보로 다시 그립니다. 대화는 최근 300개 + 실시간 꼬리, 상세는 실행 중 표시와 '🖥 터미널로 돌아가기'까지 최신입니다.
- **이미 떠 있으면**: 그대로. 폰에서 숨겨 둔 뷰어의 실시간이 끊겨 있으면 다시 엽니다.
- **지난 상태 없음**: 흐린 단추. '최근에 본 대화가 없습니다 — 세션 ⋯ → 💬 대화 보기'(목록 칸이 접혀 있으면 펼침).
- **세션이 꺼짐**: 그대로 열립니다(기록을 읽는 화면).
- **이어받음**: 이어받은 세션으로 열고 토스트로 알립니다.
- **지워짐**(삭제·이사·자동 실행 -p 라 목록에서 빠짐): 기억을 지우고 '그 세션은 목록에 없습니다'.
- **함께 고침**: 뷰어 막대에 세션 이름을 보입니다(지금은 무엇을 보는지 화면에 없음 [확인됨]).

### 4-4. 🎬 팀 관제
- **지난 상태**: 마지막으로 연 팀(팀 코드 + 관제 id + 이름). PC 상세 칸 · 폰 덮개 · 관제 알림 어느 길이든 기록합니다. 팀 코드를 먼저 씁니다(팀을 보관했다 풀면 관제 id 가 새로 생김). 필터·선택 세션은 기억하지 않고 처음 상태로 엽니다.
- **누르면**: 팀 목록을 받아 그 팀의 지금 구성원으로 관제를 엽니다. PC 는 상세 칸 안, 폰은 지금처럼 화면 전체 덮개입니다.
- **이미 떠 있고 연결이 살아 있으면**: 그대로. 끊겨 있으면 다시 연결합니다(지금은 무반응 [확인됨]).
- **지난 상태 없음**: 관제할 수 있는 팀이 1개면 바로 엽니다(읽기 전용이라 안전). 여러 개면 목록 칸을 👥 팀 보기로(접혀 있으면 펼침) + '팀 ⋯ → 🎬 관제 열기'. 0개면 '관제할 팀이 없습니다'.
- **관리 세션이 꺼짐**: 그대로 열립니다(기록을 읽음). 새 활동만 오지 않습니다.
- **팀 삭제·보관·관리 세션 없음**: 기억을 지우고 '그 팀 관제를 열 수 없습니다'.
- **통신 실패**: 기억을 지우지 않고 '연결을 확인하세요'. 지금은 통신 실패도 '찾을 수 없음'으로 보입니다 [확인됨: 코드].
- 작업 장부는 이번 대상이 아닙니다(지금처럼 팀 ⋯ 에서). 원하시면 나중에 🎬 칸에 넣을 수 있습니다.

### 4-5. 웹 재개 · 작업 장부
- 바로가기 대상이 아닙니다. 이 화면에 있다가 단추를 누르면 정리하고 이동합니다.
- 웹 재개를 떠나면 그 재개(claude -p)를 끝냅니다. 응답 중이면 끊지 않고 그 응답이 끝난 뒤 닫고 알립니다(결정 7).

## 5. 폰

### 5-1. 들어가는 곳: 제목 ▾

```
┌──────────────────────────────────┐
│ ● 터미널 재개 ▾ [내PC▾]  🖧 🔔 ⚙ │ ← 제목을 누르면
├──────────────────────────────────┤
│                                  │
│         (터미널 전체 화면)         │
│                                  │
├──────────────────────────────────┤ ← 아래에서 올라오는 시트
│ 화면 바로 가기                     │
│ 🖥 터미널   개인비서 · 입력 대기 · 탭 3   지금 │
│ 📄 파일     report.md 외 2               │
│ 💬 뷰어     ClewPath 개발 · 3분 전        │
│ 🎬 팀 관제  006 개발팀                   │
└──────────────────────────────────┘
```

- 제목(지금 화면 이름) 옆에 ▾ 를 붙여 단추로 만듭니다. 머리 줄 폭은 ▾ 한 글자만 늡니다. 390px 에서 머리 줄이 넘쳤던 전례가 있어 단추를 새로 늘리지 않습니다.
- 시트는 ⋯·🔔 와 같은 아래 시트입니다. 줄 순서는 늘 같고, 지금 화면 줄엔 '지금', 숨겨 둔 화면엔 '바로 돌아가기', 기억이 없는 줄은 흐리게 '고르기…'.
- 머리 줄은 목록 · 상세 · 터미널 전체 화면 · 편집기 · 뷰어 · 장부 어디서나 보입니다. 아래 탭 막대는 터미널·편집기 전체 화면에서 숨지만 머리 줄은 남습니다 [확인됨]. 그래서 터미널을 보다가 바로 파일로 갈 수 있습니다.

### 5-2. 숨겨 둔 화면으로 즉시 돌아가기

```
┌──────────────────────────────────┐
│ ● 세션 ▾  [내PC▾]        🖧 🔔 ⚙ │
├──────────────────────────────────┤
│  (세션 목록)                      │
├──────────────────────────────────┤
│ 화면 바로 가기                     │
│ 🖥 터미널   CMS 작업 · 탭 2   바로 돌아가기 │ ← 재접속 없이 즉시
│ 📄 파일     열어 둔 파일 없음 · 고르기…    │ ← 흐림
│ 💬 뷰어     북한법 챗봇 · 10분 전          │
│ 🎬 팀 관제  006 개발팀                  │
└──────────────────────────────────┘
```

- '‹ 목록'과 아래 탭 막대는 상세 칸을 숨기기만 하므로 [확인됨: 하네스 P1·P8b], 시트에서 그 화면을 고르면 다시 보여 주기만 합니다. 재접속도 다시 받기도 없습니다.
- 숨긴 사이 앱 전환으로 연결이 끊겼으면 보여 준 뒤 같은 탭에 다시 붙습니다(지금 재접속 규칙). 다른 기기가 가져간 탭, claude 가 끝난 탭은 자동으로 다시 붙이지 않습니다(지금 규칙).
- 상세 칸이 빈 안내뿐이면 이 길을 쓰지 않습니다. 폰은 빈 안내가 숨겨져 있어 막다른 빈 화면이 되기 때문입니다 [확인됨].
- 함께 고침: '‹ 목록' 뒤 같은 세션 줄 · 같은 세션 알림을 누르면 이제 숨은 터미널이 보입니다(지금은 무반응 [확인됨: 하네스 P1]).

### 5-3. 팀 관제 덮개

```
┌──────────────────────────────────┐
│ 🎬 006 개발팀  ● live   ◨   ▾   ✕ │ ← 관제 머리의 ▾ = 같은 시트
```

- 폰 팀 관제는 화면 전체를 덮어 머리 줄까지 가립니다 [확인됨]. 그래서 관제 머리에도 같은 ▾ 를 둡니다(결정 10).
- 다른 화면을 고르면 덮개를 닫고 이동합니다. 토스트는 덮개를 닫은 뒤 띄웁니다(덮개가 토스트를 가림 [확인됨: CSS z-index 60 > 20]).
- 지금 팝·시트는 덮개보다 아래 층에 뜹니다(덮개 60, 시트 41 [확인됨: CSS]). 관제 머리에서 연 시트는 덮개보다 위 층으로 올립니다.

### 5-4. 그대로인 것
- 아래 탭 막대(💬 세션 · 👥 팀 · 📁 파일 · 🧑‍💼 비서)는 목록 보기 전환만 합니다. 바로가기를 거기 넣지 않는 이유: 터미널·편집기 전체 화면에서 탭 막대가 숨어 가장 필요할 때 손이 닿지 않습니다.
- 폰에는 단축키가 없습니다.

### 5-5. 앱(Capacitor)
- 웹 수정은 앱을 다시 빌드해야 앱에 들어갑니다(PWA 는 Host 릴리스만으로 릴레이에 반영).
- 앱 아래 바의 '터미널' 단추는 터미널 화면이 남아 있으면 바째 숨어 실제로 누를 수 없습니다 [코드 확인됨, 실기 확인 필요]. 다시 빌드할 때 이 단추를 바로가기(터미널)로 바꾸거나 빼서 제목 ▾ 하나로 모읍니다.

### 6-2. 복원 규칙
- **새로고침·앱 다시 열기**: 아무 화면도 저절로 열지 않습니다(결정 6). 첫 목록을 받은 뒤 순서는 알림 진입(#open=) → 터미널 탭 목록 복원 → 관제 알림(#monitor=) → 승인 알림 → 바로가기 단추 켜기입니다. PC 빈 칸에는 '최근 화면'이 보입니다.
- 터미널 탭 복원은 알림으로 이미 정해진 마지막 탭을 덮지 않습니다(지금은 로컬에서 덮음 [확인됨: probe4]).
- **누를 때 검증**: 기억한 세션·팀이 아직 있는지 확인하고, 없으면 그 기억만 지우고 알립니다.
- **릴레이 재연결(같은 페이지)**: 기억 그대로, 화면이 저절로 바뀌지 않습니다. 터미널이 실제로 떠 있을 때만 지금처럼 다시 붙습니다.
- **PC 전환(릴레이)**: 상세 칸 · 터미널 탭 · 파일 상태 · 지금 화면을 비우고 새 PC 의 기억을 씁니다. 받아 둔 팀 목록·팀 상세도 비우고,
  팀 목록은 청한 PC 가 지금 PC 일 때만 바꿉니다(0.31.0 검토 — 이전 PC 의 팀 이름이 새 PC 의 🎬·시트·최근 화면에 보였다).
- **기기마다 따로**: PC 와 폰은 서로의 '마지막'을 공유하지 않습니다. 기기마다 하던 일이 다르기 때문입니다(나중에 PC 에 저장해 공유하는 선택지는 남겨 둠).
- **같은 기기의 창 두 개**: 나중에 저장한 창이 이깁니다(감수).

### 바뀌는 것
1. 머리 줄: PC 단추 4개, 폰 제목 ▾(폰 관제 머리에도 ▾).
2. 터미널에서 목록 줄·⋯ 등으로 상세 · 뷰어 · 재개 · 장부로 가면 그 자리에서 터미널 화면을 정리합니다(연결 닫음). 돌아올 때 다시 짓는 것은 지금과 같습니다. 대신 재연결 · 폰 화면 복귀 · PC 재기동 때 보던 화면이 터미널로 바뀌던 일이 없어집니다.
3. 폰: '‹ 목록' 뒤 같은 세션 줄·같은 세션 알림을 누르면 숨은 터미널이 보입니다.
4. 뷰어 · 재개 · 빈 안내로 가면 그 세션 알림이 더는 무시되지 않습니다.
5. 뷰어에서 재개로 가면 뷰어 실시간 연결이 닫힙니다.
6. 릴레이: 관제 · 뷰어 · 웹 재개 · 탭 배지 연결을 닫으면 PC 에도 닫기 신호를 보냅니다.
7. 터미널을 떠났다가 20초 안에 돌아와도 가짜 인계 확인창이 뜨지 않습니다.
8. 같은 팀 관제가 끊겨 있으면 '관제 열기'·🎬 가 다시 연결합니다. 관제 알림은 다른 팀 관제가 떠 있어도 그 팀으로 바꿉니다(원치 않으시면 지금처럼 둘 수 있음).
9. 웹 재개 화면을 떠나면 그 재개를 끝냅니다(결정 7).
10. 파일 편집기로 돌아오면 스크롤 위치가 남고, 목록 전에 연 파일 오류가 굳지 않습니다.
11. 2차 인증 창을 취소해도 보던 뷰어의 실시간 연결이 끊기지 않습니다.
12. 기억이 PC 별로 나뉘고, 릴레이 PC 전환 때 이전 PC 의 화면·탭을 비웁니다.
13. 빈 상세 칸에 '최근 화면' 단추와 접힘 상태에 맞는 문구, 뷰어 막대에 세션 이름.
